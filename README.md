# 듀얼 모멘텀 & 마켓 타이밍 실행기

유안타증권(TRADER) 실전 매매에 즉시 활용할 수 있는 동적 자산배분 및 가중 모멘텀 산출 웹 대시보드입니다. 실시간 금융 데이터를 연동하여 시장 리스크를 관리하고 최적의 리밸런싱 비중을 계산합니다.

주요 기능

일일 리스크 체크: 코스피, 코스닥, S&P 500 최신 지수와 20일 이동평균선을 비교하여 시장 진입/현금화 신호(🟢/🔴) 직관적 판별

가중 모멘텀(WMS) 평가: 3, 6, 9, 12개월 과거 수익률에 차등 가중치(9:6:3:1)를 부여하여 최근 트렌드에 민감한 주도 자산 랭킹 산출

실전 매수 계산기: 입력된 매수 가능 예수금과 실시간 1호가를 바탕으로 정확한 목표 매수 주수 및 잔여 현금 자동 도출

구동 환경 및 기술

Python, Streamlit, FinanceDataReader, Pandas

내용을 붙여넣고 우측 상단의 Commit changes를 눌러 저장을 완료하셨다면, 새 인터넷 창을 열고 스트림릿 클라우드(https://share.streamlit.io/)에에) 접속하여 마지막 배포 단계를 이어서 진행해 주시면 됩니다.
